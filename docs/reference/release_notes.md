# Release notes

Release descriptions are optional; publishing does not require an entry
here. List any entries newest first, with the release id as a heading and
a one-sentence description of its purpose or notable change. For example:

```markdown
## example-release

Initial benchmark results for the tabular datasets.
```

Entries can also mention known caveats or name a release they correct.
Coverage and producing commits are recorded automatically in the
[release manifest](release_manifest.md); they do not need to be repeated or
analysed here.
