# chronic_kidney_disease.csv

`chronic_kidney_disease.csv` is the UCI Machine Learning Repository's
dataset 336, "Chronic Kidney Disease"
(<https://archive.ics.uci.edu/dataset/336/chronic+kidney+disease>), as
`ucimlrepo` returns it, the label `class` last as `target`, 1 for chronic
kidney disease.

[`docs/reference/datasets/ckd.md`](../../docs/reference/datasets/ckd.md).
