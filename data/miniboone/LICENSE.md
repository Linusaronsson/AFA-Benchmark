# miniboone.csv

`miniboone.csv` is `MiniBooNE_PID.txt` of the UCI Machine Learning
Repository's dataset 199, "MiniBooNE particle identification"
(<https://archive.ics.uci.edu/dataset/199/miniboone+particle+identification>),
as a CSV: the first line of event counts dropped, the columns named and the
label `Outcome` added, 1 for the signal events.

The dataset is licensed under the Creative Commons Attribution 4.0
International license (CC BY 4.0,
<https://creativecommons.org/licenses/by/4.0/>). Cite B. Roe, MiniBooNE
particle identification [Dataset], UCI Machine Learning Repository (2005),
doi:10.24432/C5QC87, and the paper listed in
[`docs/reference/datasets/miniboone.md`](../../docs/reference/datasets/miniboone.md).
